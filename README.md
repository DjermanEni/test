# RWRD Character Bot

Telegram-бот для парсинга анкет персонажей с форума Cyberpunk: Rewired.

## Возможности

- Парсит все страницы форума (до 25 страниц)
- Кэширует данные на 1 час
- Поддерживает поиск по имени и позывному
- Форматирует ответ в Markdown

## Команды

- `/start` — приветствие
- `/char Имя` — найти анкету персонажа
- `/list` — список всех персонажей
- `/help` — помощь

## Установка

1. Получите токен бота у [@BotFather](https://t.me/BotFather)
2. Откройте `bot.py` и замените `YOUR_BOT_TOKEN_HERE` на ваш токен
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите: `python bot.py`

## Деплой на Bothost

1. Загрузите файлы в репозиторий на GitHub
2. Перейдите на [bothost.ru](https://bothost.ru)
3. Создайте бота, указав ссылку на репозиторий и токен
